# Free Photo Editor

**by [Bhawesh Tibrewal](https://bhaweshtibrewal.com)**

A free photo editor for everyone, for life. It runs in your browser, so your photos stay on your device.

Free Photo Editor is a free, open-source alternative to Photoshop: a layer-based photo and image editor that runs in any
modern browser on phones, tablets and computers. It is being built to open and save PSD files, to work offline, to install
as an app on Windows, Mac, Linux and Android, and to give AI agents such as Claude a photo editor they can use through an
MCP server and a command-line tool. No sign-up, no watermark, no subscription.

> **Status: in development.** The first version is being built now. Star or watch this repository to see it land.
> It will live at **https://bhaweshtibrewal.com/tools/free-photoeditor**.

## A free Photoshop alternative that keeps your photos private

The editor runs entirely on your own device. Your photos are never uploaded to a server, and the code is open source,
so anyone can check exactly what it does. It is designed for phones first, then tablets and computers.

## A photo editor for AI agents (MCP and CLI)

Free Photo Editor is being built so AI agents can use it too. A local **MCP server** (Model Context Protocol, the
standard way tools plug into AI assistants such as Claude) and a **command-line tool** will let an agent open, edit,
convert and export images on your own computer, for free, with no upload and no account. Planned.

## Questions people ask

**Is Free Photo Editor really free?**
Yes. It is free for everyone, for life: no subscription, no sign-up, no watermark. The code is open source under the
AGPL-3.0 licence.

**Is it a free alternative to Photoshop?**
It is being built as a free, open-source alternative for everyday Photoshop work: layers, PSD files, brushes,
adjustments and filters, in your browser. It is an independent project and is not made by or connected with Adobe.

**What is the best free Photoshop alternative?**
It depends on what you need. GIMP and Krita are free, open-source desktop apps. Photopea runs in the browser, but its
code is not open. Free Photo Editor aims to be both open source and in the browser, phone-first, and usable by AI
agents.

**Can I open and edit PSD files for free?**
Opening PSD files with their layers, and saving back to PSD, is part of the first version being built now.

**Does it upload my photos?**
No. It runs in your browser on your own device, so your photos stay with you.

**Does it work on my phone?**
Yes, that is the first design goal: touch gestures, pen pressure and layouts made for small screens.

**Can Claude or other AI agents use it?**
That is planned: a local MCP server and a command-line tool, so AI agents can edit images on your computer for free.

**Does it work offline?**
Planned: install it from your browser and it keeps working without internet.
