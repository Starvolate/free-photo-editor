# Free Photo Editor

**by [Bhawesh Tibrewal](https://bhaweshtibrewal.com)**

A free photo editor for everyone, for life. It runs in your browser, so your photos stay on your device.

**Status:** being built. It will live at https://bhaweshtibrewal.com/tools/free-photoeditor, with apps for Windows, Mac,
Linux, Android and iPhone, plus a command-line tool and an MCP server so AI agents can use it on your own computer.
